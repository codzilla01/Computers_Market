# تِك ماركت للكمبيوتر — متجر إلكتروني متكامل لأجهزة الكمبيوتر وملحقاتها

متجر إلكتروني متكامل بواجهة عربية (`RTL`) احترافية وخلفية برمجية (`Node.js + Express + SQLite`) يضم واجهة تسوّق حديثة، سلة مشتريات، نظام إتمام طلب مع حساب الشحن والضريبة وأكواد الخصم، تتبع للطلبات، ولوحة إدارة متكاملة للمنتجات والمخزون والطلبات والرسائل والإعدادات.

## المميزات الرئيسية

### واجهة المتجر للعملاء (`/`)
- **تصميم عربي متجاوب (`RTL`)** مع قائمة جوال جانبية وخط `Cairo` وأصول صور محلية محسّنة بالكامل بدون روابط خارجية معطلة.
- **بحث وتصفية وفرز متقدم:** البحث الفوري بالاسم أو المعالج أو المواصفات أو رمز SKU، التصفية بالعلامة التجارية (عبر بطاقات العلامات التجارية التفاعلية أو القائمة) والفئة وحالة التوفر والمفضلة، والفرز بالسعر والتقييم والأحدث.
- **سلة مشتريات متكاملة (Cart Drawer):**
  - حفظ تلقائي في المتصفح ومزامنة مع المخزون الفعلي من الخادم.
  - شريط تقدم الشحن المجاني، تطبيق أكواد الخصم (مثل `SAVE10`، `WELCOME5`، `PRO300`)، وحساب تلقائي للشحن وضريبة القيمة المضافة (`15%`).
  - إمكانية إرسال محتويات السلة مباشرة عبر واتساب.
- **إتمام الطلب (Checkout) وإصدار الفاتورة:**
  - حساب الأسعار والخصم والضريبة من الخادم لضمان الدقة والأمان.
  - خصم المخزون تلقائياً عبر معاملات قاعدة بيانات ذرّية (`SQLite Transactions`) لمنع البيع فوق المخزون.
  - دعم خيارات الدفع: عند الاستلام، بطاقة إلكترونية (بيئة تجريبية جاهزة للربط مع Moyasar/Tap/Stripe)، والتحويل البنكي.
  - شاشة تأكيد مع رقم تتبع فريد وخيار طباعة الفاتورة.
- **تتبع الطلبات (`#track-order`):** متابعة مراحل الطلب الأربع (تم الاستلام ← جاري التجهيز ← تم الشحن ← تم التوصيل).
- **نموذج تواصل فعّال وصفحة سياسات قانونية (`/policies`):** الضمان، الاستبدال والاسترجاع، الشحن، والخصوصية.

### لوحة إدارة المتجر (`/admin`)
- **حماية وتسجيل دخول آمن:** كلمات مرور مشفرة بـ `bcryptjs` وجلسات موقّعة بـ `HMAC-SHA256` في كوكيز `HttpOnly`.
- **لوحة إحصائيات (Dashboard):** إجمالي المبيعات، حالات الطلبات، تنبيهات انخفاض المخزون مع إعادة تعبئة سريعة، وتوزيع المخزون حسب العلامة التجارية.
- **إدارة المنتجات (CRUD كاملة):** إضافة وتعديل وحذف المنتجات، تعديل المخزون السريع، محرر ديناميكي للمواصفات الفنية، ورفع صور المنتجات مباشرة (`Multer`).
- **إدارة الطلبات:** البحث والتصفية وتحديث حالة الطلب (مع استعادة المخزون تلقائياً عند الإلغاء) وعرض تفاصيل الطلب الكاملة.
- **إدارة أكواد الخصم ورسائل العملاء وإعدادات المتجر:** تعديل بيانات المتجر والشحن والضريبة وتغيير كلمة مرور المدير من داخل اللوحة.

## التشغيل المحلي

المتطلبات: **Node.js 22.5+**

```bash
npm install
npm start
```

سيعمل المتجر على:
- واجهة المتجر: `http://localhost:3000/`
- لوحة الإدارة: `http://localhost:3000/admin`
- صفحة السياسات: `http://localhost:3000/policies`

### بيانات الدخول الافتراضية للوحة الإدارة
- **البريد الإلكتروني:** `admin@computers-market.sa`
- **كلمة المرور:** `Admin@2026`

> يُنصح بتغيير كلمة المرور من قسم **إعدادات المتجر** أو عبر متغيرات البيئة (`ADMIN_EMAIL`, `ADMIN_PASSWORD`, `SESSION_SECRET`) قبل النشر الفعلي.

## بنية المشروع

```text
├── server.js               # خادم Express وإعدادات الأمان والمسارات
├── db/database.js          # قاعدة بيانات SQLite والجداول والبيانات الأولية
├── middleware/auth.js      # التحقق من جلسة المدير وتوقيع الكوكيز
├── routes/                 # مسارات REST API (المنتجات، الطلبات، الكوبونات، الرسائل، الإدارة)
├── public/                 # الواجهات الأمامية (المتجر، لوحة التحكم، السياسات، CSS، JS، الصور)
└── tests/api.test.js       # اختبارات تكامل شاملة للـ API والمنطق التجاري
```
